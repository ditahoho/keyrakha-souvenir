LANGKAH UPGRADE DARI V9
1. Backup folder V9 Anda.
2. Gunakan file project V10.
3. Salin URL dan Publishable Key Supabase Anda ke js/supabase-config.js bila file masih placeholder.
4. Supabase > SQL Editor > New Query.
5. Jalankan isi file 05-product-labels-promo-v10-migration.sql SATU KALI.
6. Refresh admin/index.html.
7. Edit/tambah produk lalu pilih label yang diperlukan.

CATATAN PROMO
- Harga promo wajib lebih rendah dari harga normal.
- Tanggal promo boleh dikosongkan.
- Jika tanggal diisi, badge dan harga promo hanya aktif pada periode tersebut.
- Satu produk boleh memiliki beberapa label sekaligus.
